Logins de sites

    
Para dashboards de outros sites (BOSS, OpenFlow…). Quando um painel desse endereço mostrar a tela de login, o Scry preenche usuário e senha e clica em entrar sozinho. A senha fica guardada protegida pelo Windows e nunca é mostrada de volta. Use um usuário só leitura, criado só para a parede.

Novo login

    

      

      

      

      

    

    
    
    
Use quando cada painel tem o seu usuário: cadastre um login por painel, com o mesmo endereço. Painéis com o mesmo login dividem uma única sessão (só um entra; os outros usam a sessão dele).

    
    

      Avançado: quando o Scry não acha os campos sozinho
      
Seletores CSS opcionais. Em branco, o Scry usa o campo de senha da tela, o campo de texto antes dele e o botão Entrar/Login. Exemplo: #username, input[name=senha], button.btn-login.
